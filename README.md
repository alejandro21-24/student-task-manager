# Student Task Manager

## Project Description

Student Task Manager is a web application designed to help college students organize their assignments, manage deadlines, and track academic progress. The goal of this project is to make it easier for students to manage their schoolwork and stay organized.

## Main Features

- Add new assignments.
- Edit and delete existing assignments.
- Set due dates for assignments.
- Mark assignments as completed.
- Organize assignments by class.
- View upcoming assignments.

## Technology Stack

- **Frontend:** React
- **Backend:** Node.js and Express
- **Database:** SQLite
- **Containerization:** Docker
- **CI/CD:** GitHub Actions
- **Cloud Hosting:** Google Cloud Platform
- **Version Control:** Git and GitHub
- **Project Management:** Jira
- **Documentation:** Confluence

The first version of the application will allow students to create, edit, delete, and complete assignments. Students will also be able to set deadlines and save their assignments.
